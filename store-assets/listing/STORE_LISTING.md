## Куда вставлять в консолях

### Google Play Console
1. Main store listing → название / краткое / полное  
2. Graphics → icon 512 (из icon-1024), feature graphic, phone screenshots  
3. Store settings → Privacy policy = https://vay-master.ru/privacy  
4. App content → Data safety по таблице выше  

### App Store Connect
1. App Information → Privacy Policy URL  
2. Version → Screenshots 6.7 / 6.1  
3. Description / Keywords / Support URL  
4. App Review Information → Notes for Review (блок EN выше) + тестовые логины
