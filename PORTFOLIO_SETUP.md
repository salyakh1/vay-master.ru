# Настройка системы портфолио для мастеров

## Описание

Система портфолио позволяет мастерам добавлять свои работы с фото и видео, которые отображаются в их профиле в виде сетки 3x3.

## Функционал

1. **Добавление работ**: Мастера могут добавлять работы через страницу `/portfolio/new`
2. **Сетка портфолио**: Работы отображаются в профиле мастера в сетке 3x3
3. **Просмотр работы**: При клике на работу открывается галерея с возможностью листать все фото/видео
4. **Медиа**: К каждой работе можно добавить до 10 фото и до 5 видео
5. **Описание**: К каждой работе можно добавить название и описание

## Установка

### 1. Применить SQL схему

1. Откройте Supabase Dashboard → **SQL Editor**
2. Скопируйте содержимое файла `supabase/portfolio_schema.sql`
3. Вставьте в SQL Editor и выполните (Run)

Это создаст таблицу `portfolio_items` с необходимыми полями и RLS политиками.

### 2. Проверка

После применения схемы проверьте:
- Таблица `portfolio_items` создана
- RLS политики активны
- Триггер `update_portfolio_items_updated_at` работает

## Использование

### Для мастеров:

1. Перейдите в свой профиль
2. В разделе "Портфолио" нажмите "Добавить работу"
3. Заполните форму:
   - Название работы (обязательно)
   - Описание (опционально)
   - Загрузите фото (до 10 штук)
   - Загрузите видео (до 5 штук)
4. Нажмите "Добавить работу"

### Для всех пользователей:

1. Перейдите на профиль мастера
2. В разделе "Портфолио" увидите сетку работ
3. Кликните на любую работу для просмотра в режиме галереи
4. В галерее можно листать фото/видео стрелками или кликами

## Структура базы данных

### Таблица `portfolio_items`:

- `id` (UUID) - уникальный идентификатор
- `master_id` (UUID) - ID мастера
- `title` (TEXT) - название работы
- `description` (TEXT) - описание работы
- `images` (TEXT[]) - массив URL фото
- `videos` (TEXT[]) - массив URL видео
- `created_at` (TIMESTAMP) - дата создания
- `updated_at` (TIMESTAMP) - дата обновления

## RLS Политики

- **SELECT**: Все могут просматривать работы
- **INSERT**: Только мастера могут создавать работы
- **UPDATE**: Мастера могут обновлять только свои работы
- **DELETE**: Мастера могут удалять только свои работы
