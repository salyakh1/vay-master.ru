# Планерка: напольные покрытия, покрытия стен и мастера

## Откуда данные в проекте

| Что | Таблица / источник |
|-----|---------------------|
| **Каталог товаров (напольные покрытия)** | `product_categories` (секция `finishing`, slug `flooring`) + `product_subcategories` |
| **Услуги мастеров (для выбора в планерке)** | `services` (привязаны к `specializations`) |
| **Мастера, выполняющие услуги** | `profiles` (role = master) + `profile_services` (связь мастер ↔ услуга) |

## 1. Напольные покрытия (каталог товаров)

Список из нашей системы — категория **«Полы и напольные покрытия»** (`product_categories.slug = 'flooring'`), подкатегории (`product_subcategories`):

| Название | Slug подкатегории |
|----------|-------------------|
| Ламинат | flooring-laminate |
| Паркет | flooring-parquet |
| Линолеум | flooring-linoleum |
| Ковролин | flooring-carpet |
| ПВХ плитка | flooring-vinyl |
| Подложки | flooring-underlay |
| Плинтусы | flooring-baseboards |
| Пороги | flooring-thresholds |
| Масла и лаки | flooring-finishes |
| Теплый пол (покрытия) | flooring-floor-heat |

Товары в планерке (рекомендации) берутся из `products` с `category_ref.section = 'construction'` и при выбранной услуге — по ключевым словам. Для пола можно сузить до категории `flooring` и подкатегорий выше.

## 2. Услуги для пола (список для планерки)

Чтобы в планерке в выпадающем списке «Материал для пола» были пункты, в БД должны быть **услуги** (таблица `services`), привязанные к специализациям по полу.

### Специализации

- **Стяжка и наливной пол** (`specializations.slug = 'floor-screed'`)
- **Паркет/ламинат** (`specializations.slug = 'flooring'`)

### Услуги (вносятся сидом)

**Стяжка и наливной пол:**

- Полусухая стяжка  
- Мокрая стяжка  
- Наливной пол  
- Армирование стяжки  
- Стяжка пола  
- Теплый пол в стяжке  
- Гидроизоляция пола  
- Шлифовка стяжки  

**Паркет/ламинат и покрытия:**

- Укладка ламината  
- Укладка паркета  
- Укладка линолеума  
- Укладка ковролина  
- Пробковое покрытие  
- Шлифовка и циклевка паркета  
- Лак/масло для паркета  
- Подложка и подготовка пола  
- Плинтус и порожки  
- Ремонт пола  
- Теплый пол (монтаж)  

Сид: **`supabase/planner_floor_services_seed.sql`** — выполнить в Supabase SQL Editor один раз.

## 3. Мастера, которые выполняют эти услуги

- Мастер указывает услуги в онбординге или в профиле (выбор из `services`).
- Связь хранится в **`profile_services`** (profile_id, service_id).
- В планерке при выборе материала/услуги запрос идёт так:
  - выбранная услуга → `profile_services.service_id = эта услуга`
  - по `profile_id` загружаются профили с `role = 'master'`
- В блоке «Мастера (из нашей системы)» выводятся именно эти мастера.

Итого: **напольные покрытия** — из каталога товаров (`product_categories` + `product_subcategories`); **список для выбора в планерке** — из `services` (сид по полу); **мастера** — из `profiles` + `profile_services`.
