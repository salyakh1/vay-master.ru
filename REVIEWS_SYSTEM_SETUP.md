# Система отзывов и рейтингов - Инструкция по установке

## Что реализовано

Система отзывов позволяет всем пользователям оставлять отзывы:
- **О мастерах** - любой пользователь может оставить отзыв о мастере
- **О товарах** - любой пользователь может оставить отзыв о товаре
- **Ответы на отзывы** - авторы отзывов и владельцы (мастера/продавцы) могут отвечать на отзывы

## Возможности

✅ Рейтинг от 1 до 5 звезд  
✅ Текстовые комментарии (до 1000 символов)  
✅ Фотографии к отзывам (до 5 шт.)  
✅ Ответы на отзывы  
✅ Автоматический расчет среднего рейтинга  
✅ Ограничение: один пользователь = один отзыв на мастера/товар  
✅ Защита: нельзя оставить отзыв самому себе  

## Установка

### 1. Применить SQL миграцию

1. Откройте Supabase Dashboard → SQL Editor
2. Скопируйте содержимое файла `supabase/reviews_schema.sql`
3. Выполните SQL скрипт

### 2. Что создается

**Таблицы:**
- `master_reviews` - отзывы о мастерах
- `product_reviews` - отзывы о товарах
- `review_replies` - ответы на отзывы

**Поля в существующих таблицах:**
- `profiles.master_rating` - средний рейтинг мастера
- `profiles.master_reviews_count` - количество отзывов о мастере
- `profiles.seller_rating` - средний рейтинг продавца (на основе отзывов о товарах)
- `profiles.seller_reviews_count` - количество отзывов о продавце
- `products.rating` - средний рейтинг товара
- `products.reviews_count` - количество отзывов о товаре

**Функции:**
- `update_master_rating()` - обновляет рейтинг мастера
- `update_seller_rating()` - обновляет рейтинг продавца
- `update_product_rating()` - обновляет рейтинг товара
- `update_updated_at_column()` - обновляет поле updated_at

**Триггеры:**
- Автоматическое обновление рейтингов при создании/изменении/удалении отзыва
- Автоматическое обновление поля `updated_at`

**RLS политики:**
- Все могут читать отзывы
- Только авторизованные пользователи могут создавать отзывы
- Только автор отзыва может редактировать/удалять свой отзыв
- Только автор отзыва или владелец (мастер/продавец) могут отвечать на отзывы

## Использование

### В профиле мастера

Отзывы отображаются в секции "Отзывы" после портфолио:
- Средний рейтинг с количеством отзывов
- Кнопка "Оставить отзыв" (для не владельца профиля)
- Список отзывов с возможностью редактирования/удаления
- Форма для ответа на отзыв (для мастера)

### В профиле продавца

Отзывы о товарах продавца отображаются в секции "Отзывы" после товаров:
- Средний рейтинг с количеством отзывов
- Список отзывов о товарах продавца
- Форма для ответа на отзыв (для продавца)

### На странице товара

Отзывы о конкретном товаре отображаются в секции "Отзывы о товаре":
- Средний рейтинг товара с количеством отзывов
- Кнопка "Оставить отзыв" (для не владельца товара)
- Список отзывов с возможностью редактирования/удаления
- Форма для ответа на отзыв (для продавца)

## Компоненты

- `RatingStars` - компонент для отображения и выбора рейтинга (1-5 звезд)
- `ReviewCard` - карточка отзыва с информацией о рецензенте, рейтинге, комментарии, фотографиях
- `ReviewForm` - форма для создания/редактирования отзыва
- `ReviewReplyForm` - форма для ответа на отзыв

## API Endpoints

- `GET /api/reviews?type=master&targetId=...` - получить отзывы о мастере
- `GET /api/reviews?type=product&targetId=...` - получить отзывы о товаре
- `POST /api/reviews` - создать отзыв
- `PUT /api/reviews/[id]` - обновить отзыв
- `DELETE /api/reviews/[id]` - удалить отзыв
- `POST /api/reviews/replies` - создать ответ на отзыв

## Важные замечания

1. **Один отзыв на пользователя** - система не позволяет создать второй отзыв от того же пользователя на того же мастера/товар. Можно только редактировать существующий.

2. **Защита от самопродвижения** - нельзя оставить отзыв самому себе (проверка в SQL и API).

3. **Автоматический расчет рейтинга** - рейтинг обновляется автоматически при каждом изменении отзывов благодаря триггерам.

4. **Хранение фотографий** - фотографии отзывов хранятся в Supabase Storage в папке `reviews/{targetId}/`.

5. **RLS политики** - все отзывы читаемы всеми, но редактировать/удалять может только автор.

## Статистика

Рейтинги и количество отзывов автоматически отображаются в:
- Статистике продавца (профиль)
- Карточке мастера (поиск)
- Карточке товара (страница товара)
