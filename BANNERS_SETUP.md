## 2. Настройка Storage для изображений

### Вариант 1: Через Supabase UI

1. Перейдите в **Storage** в Supabase Dashboard
2. Создайте новый bucket с именем `banner-images`
3. Установите **Public bucket** = `true`
4. Примените RLS политики из файла `supabase/banner_storage_setup.sql`

### Вариант 2: Через SQL

Выполните SQL скрипт `supabase/banner_storage_setup.sql` в Supabase SQL Editor.

**Примечание:** Создание bucket через SQL может требовать специальных прав. Рекомендуется использовать UI.

## 3. Проверка работы

1. Войдите в админ-панель (`/admin`)
2. Перейдите в раздел **"Баннеры"**
3. Создайте тестовый баннер:
   - Загрузите изображение
   - Выберите страницы показа
   - Установите приоритет
   - Активируйте баннер

4. Проверьте отображение на страницах:
   - Главная (`/`)
   - Поиск мастеров (`/search`)
   - Заказы (`/orders`)
   - Каталог товаров (`/products`)
   - Лента (`/feed`)

## 4. Рекомендации по изображениям

**Размеры изображений:**
- Рекомендуемый размер: 1200x540px (соотношение 20:9)
- Минимальный размер: 800x360px
- Формат: JPG или PNG
- Вес: до 500KB для быстрой загрузки

**Mobile:**
- Высота: 160-180px
- Ширина: 100%

**Desktop:**
- Высота: 240-280px
- Максимальная ширина: 1200px

## 5. Типы баннеров

1. **Только изображение** - простое изображение без текста
2. **Изображение + текст** - изображение с наложенным текстом
3. **Изображение + кнопка** - изображение с текстом и кнопкой
4. **Промо мастера** - специальный баннер для продвижения мастера
5. **Промо товара** - специальный баннер для продвижения товара
6. **Промо категории** - специальный баннер для продвижения категории

## 6. Типы переходов

- **Мастер** - переход на профиль мастера
- **Товар** - переход на страницу товара
- **Категория** - переход на каталог с фильтром по категории
- **Заказ** - переход на страницу заказа
- **Внешний URL** - переход на внешний сайт
- **Нет перехода** - информационный баннер без перехода

## 7. Аналитика

Система автоматически отслеживает:
- **Просмотры** - количество показов баннера
- **Клики** - количество кликов по баннеру
- **CTR** - процент кликов от просмотров (отображается в админ-панели)

## 8. Особенности

- Автопрокрутка каждые 5 секунд
- Пауза при наведении мыши
- Пауза при свайпе (на 10 секунд)
- Поддержка свайпа на мобильных
- Навигация стрелками на desktop
- Индикаторы (точки) для перехода к конкретному баннеру
- Максимум 10 баннеров на страницу
- Сортировка по приоритету

## 9. Управление в админ-панели

В разделе **"Баннеры"** (`/admin/banners`) доступно:
- Создание баннера
- Редактирование баннера
- Дублирование баннера
- Включение/отключение баннера
- Удаление баннера
- Просмотр статистики (просмотры, клики, CTR)
- Управление периодами показа
- Выбор страниц показа
- Установка приоритета

## 10. Troubleshooting

**Баннеры не отображаются:**
- Проверьте, что баннер активен (`is_active = true`)
- Проверьте, что текущая дата в пределах `start_date` и `end_date`
- Проверьте, что страница добавлена в список `pages`
- Проверьте консоль браузера на ошибки
- Если видите ошибку `infinite recursion detected in policy for relation "admin_roles"`, выполните `supabase/fix_banners_rls.sql`

**Изображения не загружаются:**
- Убедитесь, что bucket `banner-images` создан и публичен
- Проверьте RLS политики для bucket
- Проверьте права доступа к bucket
- **Временное решение:** Используйте прямой URL изображения (вставьте URL в поле "Или вставьте URL изображения")

**Ошибки в админ-панели:**
- Убедитесь, что у пользователя есть права администратора
- Проверьте, что таблица `ad_banners` создана
- Проверьте консоль браузера на ошибки
