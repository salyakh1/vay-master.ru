# Система уведомлений для мастеров

## Описание

Реализована система автоматических уведомлений для мастеров о новых заказах, соответствующих их специализациям.

## Что было сделано

1. **Таблица уведомлений** (`notifications`) - хранит все уведомления пользователей
2. **Маппинг категорий заказов → специализации** (`order_category_specialization`) - связывает категории заказов с специализациями
3. **Автоматический триггер** - при создании нового заказа автоматически создаются уведомления для мастеров с подходящими специализациями
4. **Форма создания заказа** - теперь использует реальные специализации из БД вместо статического списка
5. **Вкладка "По моим специализациям"** - на странице заказов для мастеров
6. **UI уведомлений** - бейдж с количеством непрочитанных уведомлений в Navbar и на странице заказов

## Как применить

### Шаг 1: Применить SQL миграцию

1. Откройте Supabase Dashboard: https://supabase.com/dashboard
2. Выберите ваш проект
3. Перейдите в раздел **SQL Editor**
4. Откройте файл `supabase/notifications_system.sql`
5. Скопируйте весь SQL код из файла
6. Вставьте код в SQL Editor
7. Нажмите **Run** (или F5)

Это создаст:
- Таблицу `notifications`
- Таблицу `order_category_specialization` с маппингом категорий
- Функцию `notify_masters_on_new_order()`
- Триггер `trigger_notify_masters_on_new_order`

### Шаг 2: Проверка

После применения миграции проверьте:

1. **Таблицы созданы:**
   ```sql
   SELECT * FROM notifications LIMIT 1;
   SELECT * FROM order_category_specialization LIMIT 1;
   ```

2. **Триггер активен:**
   ```sql
   SELECT * FROM pg_trigger WHERE tgname = 'trigger_notify_masters_on_new_order';
   ```

3. **Маппинг категорий заполнен:**
   ```sql

   ```

## Как это работает

### При создании заказа:

1. Клиент создает заказ и выбирает специализацию (категорию) из списка реальных специализаций
2. Триггер автоматически:
   - Находит специализацию, соответствующую категории заказа (через маппинг или прямое совпадение)
   - Ищет всех мастеров с этой специализацией
   - Создает уведомления для найденных мастеров

### Для мастеров:

1. **В Navbar** - иконка колокольчика с бейджем количества непрочитанных уведомлений
2. **На странице заказов** - вкладка "По моим специализациям" с бейджем
3. При переключении на вкладку "По моим специализациям" показываются только заказы, категории которых соответствуют специализациям мастера

## API Endpoints

- `GET /api/notifications` - получить все уведомления пользователя
- `GET /api/notifications/count` - получить количество непрочитанных уведомлений
- `PATCH /api/notifications` - отметить уведомления как прочитанные

## Важные замечания

1. **Маппинг категорий** - автоматически заполняется при применении миграции на основе существующих заказов и специализаций. Если нужно добавить новые категории, добавьте их вручную в таблицу `order_category_specialization`.

2. **Дубликаты уведомлений** - предотвращаются через UNIQUE constraint `(user_id, order_id, type)`.

3. **Обновление счетчика** - счетчик непрочитанных уведомлений обновляется каждые 30 секунд автоматически.

4. **Специализации мастеров** - мастер должен иметь выбранные специализации в профиле, чтобы получать уведомления и видеть заказы в разделе "По моим специализациям".
