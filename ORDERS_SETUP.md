# Настройка системы заказов

## Шаг 1: Применение SQL схемы

1. Откройте Supabase Dashboard
2. Перейдите в раздел **SQL Editor**
3. Откройте файл `supabase/orders_schema.sql`
4. Скопируйте весь SQL код
5. Вставьте в SQL Editor и выполните (Run)

Это создаст таблицы:
- `orders` - заказы
- `order_responses` - отклики мастеров на заказы

## Шаг 2: Проверка

После выполнения SQL:
- Таблицы должны появиться в разделе **Table Editor**
- RLS политики должны быть активны
- Индексы должны быть созданы

## Функционал

### Для всех пользователей:
- Просмотр списка заказов (`/orders`)
- Создание заказов (`/orders/new`)
- Просмотр деталей заказа (`/orders/[id]`)

### Для мастеров:
- Отклик на заказы с указанием цены и сообщения
- Просмотр своих откликов

### Для клиентов (авторов заказов):
- Выбор мастера из откликов
- Управление статусом заказа

## Навигация

В нижнем меню добавлена кнопка "Заказы" для всех пользователей.

## Статусы заказов:
- `new` - Новый (ожидает откликов)
- `in_progress` - В работе (мастер выбран)
- `completed` - Выполнен
- `cancelled` - Отменен

## Статусы откликов:
- `pending` - Ожидает решения
- `accepted` - Принят (мастер выбран)
- `rejected` - Отклонен
