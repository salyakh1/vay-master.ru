# Полный анализ проекта VAY-MASTER

## 📋 Общая информация

**Название проекта:** VAY-MASTER  
**Тип:** Социальная сеть для мастеров и продавцов  
**Версия:** 1.0.0  
**Статус:** В разработке (активная разработка)

**Описание:** Платформа для строителей, автомехаников и продавцов строительных материалов и инструментов. Объединяет мастеров, продавцов и клиентов в единой экосистеме.

---

## 🛠 Технологический стек

### Frontend
- **Framework:** Next.js 14.0.4 (App Router)
- **UI Library:** React 18.2.0
- **Styling:** Tailwind CSS 3.4.0
- **Language:** TypeScript 5.3.3
- **Icons:** react-icons 4.12.0
- **Date formatting:** date-fns 2.30.0

### Backend & Database
- **BaaS:** Supabase
  - PostgreSQL (база данных)
  - Supabase Auth (аутентификация)
  - Supabase Storage (файловое хранилище)
  - Realtime (real-time обновления)
- **API:** Next.js API Routes (REST API)

### Deployment
- **Platform:** Vercel
- **Region:** iad1 (US East)

### Дополнительные инструменты
- **Linting:** ESLint
- **PostCSS:** Autoprefixer
- **Fonts:** Inter, Manrope (Google Fonts)

## 🎯 Основной функционал

### 1. Система ролей пользователей

#### Мастер (Master)
- Создание публикаций о работе
- Портфолио работ (фото/видео)
- Просмотр и отклик на заказы
- Общение с клиентами через чаты
- Получение отзывов и рейтингов
- PRO подписка с расширенными возможностями

#### Продавец (Seller)
- Создание и управление товарами
- Каталог с категориями и фильтрами
- Общение с покупателями
- Получение отзывов о товарах
- PRO подписка

#### Клиент (Client)
- Просмотр ленты публикаций
- Поиск мастеров и товаров
- Создание заказов
- Общение через чаты
- Оставление отзывов

### 2. Лента публикаций (Feed)
- Просмотр работ от подписок
- Лайки и комментарии (стиль Instagram)
- Истории (Stories) - 24 часа
- Подписки на мастеров
- Фильтрация контента

### 3. Система заказов
- Создание заказов клиентами
- Отклики мастеров на заказы
- Принятие/отклонение откликов
- Статусы: новый, в работе, выполнен, отменен
- Фильтрация по категориям, статусам, городу
- Скрытие ФИО клиента для бесплатных мастеров (PRO функция)

### 4. Каталог товаров
- Разделы: Инструменты, Автозапчасти, Стройматериалы, Мебель
- Поиск по названию и описанию
- Фильтрация по категориям и городу
- Карточки товаров с фото
- Отзывы на товары
- История продавцов

### 5. Система чатов
- Личные сообщения между пользователями
- Отправка текста и изображений
- Отметка о прочтении
- Счетчик непрочитанных сообщений
- Удаление чатов
- Real-time обновления

### 6. Профили пользователей
- Персональная информация
- Аватар и обложка
- Портфолио работ (для мастеров)
- Отзывы и рейтинги
- Специализации и услуги
- PRO статус

### 7. Система отзывов
- Отзывы на мастеров (1-5 звезд)
- Отзывы на товары
- Комментарии с фото
- Ответы на отзывы
- Модерация отзывов

### 8. Истории (Stories)
- Создание историй (до 4 фото или 1 видео)
- Автоматическое удаление через 24 часа
- Просмотр историй
- Фильтрация по ролям (мастера/продавцы)
- PRO ограничение (после пробной недели)

### 9. PRO подписка
- Пробная неделя для новых мастеров/продавцов
- Расширенные возможности:
  - Публикация историй
  - Неограниченное портфолио
  - Видимость ФИО клиентов в заказах
  - Приоритет в поиске
- Управление через админ-панель
- Feature flags для отключения ограничений

### 10. Рекламная система
- Баннеры на разных страницах
- Контекстная реклама
- Типы рекламы:
  - HERO_SPONSORED (верхние промо-блоки)
  - INLINE_CONTEXT (между контентом)
  - SPONSORED_CARD (карточки в списках)
  - PROFILE_RELATED (в профилях)
  - FOOTER_BRAND (логотипы партнёров)
- Статистика просмотров и кликов
- Приоритет показа

### 11. Административная панель
- **Дашборд:** Статистика пользователей, заказов, жалоб
- **Управление пользователями:** Просмотр, редактирование, удаление
- **Управление заказами:** Модерация, изменение статусов
- **Жалобы:** Рассмотрение жалоб пользователей
- **Модерация контента:** Проверка публикаций, товаров
- **Управление баннерами:** Создание и настройка рекламы
- **PRO подписки:** Выдача/отзыв PRO статуса
- **Безопасность:** Мониторинг активности, ограничения
- **Настройки системы:** Feature flags, лимиты
- **Аналитика:** Статистика платформы
- **Отзывы:** Модерация отзывов

### 12. Система жалоб
- Подача жалоб на пользователей
- Типы: мошенничество, плохое качество, спам, домогательства
- Рассмотрение администрацией
- Статусы: новый, в рассмотрении, решено, отклонено

## 🗄 База данных (Supabase PostgreSQL)

### Основные таблицы

#### `profiles` - Профили пользователей
- Расширяет `auth.users`
- Поля: email, full_name, avatar_url, role, phone, city, description
- PRO поля: is_pro, pro_until
- Рейтинги: master_rating, master_reviews_count, seller_rating, seller_reviews_count

#### `posts` - Публикации
- Связь с пользователем
- Контент, изображения
- Счетчик лайков

#### `products` - Товары
- Связь с продавцом
- Название, описание, цена, изображения
- Категория, наличие на складе

#### `orders` - Заказы
- Связь с клиентом
- Название, описание, категория, локация
- Бюджет, статус, выбранный мастер

#### `order_responses` - Отклики на заказы
- Связь с заказом и мастером
- Цена, сообщение, статус

#### `chats` - Чаты
- Два участника (user1_id, user2_id)
- Удаление чатов (deleted_by_user_ids)

#### `messages` - Сообщения
- Связь с чатом
- Отправитель, контент, изображения
- Статус прочтения

#### `portfolio_items` - Портфолио
- Связь с мастером
- Название, описание, изображения, видео
- Счетчики лайков и комментариев

#### `portfolio_likes` - Лайки портфолио
- Связь с работой и пользователем

#### `portfolio_comments` - Комментарии к портфолио
- Связь с работой
- Автор, контент

#### `master_reviews` - Отзывы на мастеров
- Связь с мастером и рецензентом
- Рейтинг (1-5), комментарий, фото

#### `product_reviews` - Отзывы на товары
- Связь с товаром, продавцом и рецензентом
- Рейтинг, комментарий, фото

#### `review_replies` - Ответы на отзывы
- Связь с отзывом
- Автор, контент

#### `stories` - Истории
- Связь с пользователем
- Медиа (до 4 фото или 1 видео)
- Описание, срок действия (24 часа)
- Счетчик просмотров

#### `story_views` - Просмотры историй
- Связь с историей и просмотревшим

#### `follows` - Подписки
- Подписчик и подписка

#### `ad_banners` - Рекламные баннеры
- Тип, изображение, ссылка
- Страницы показа, приоритет
- Статистика просмотров и кликов
- Контекстная настройка (категории, ключевые слова, регионы)

#### `admin_roles` - Роли администраторов
- Типы: super_admin, moderator, support
- Активность, даты создания/обновления

#### `user_restrictions` - Ограничения пользователей
- Типы: temporary_limit, hidden_from_search, frozen, banned
- Причина, срок действия

#### `complaints` - Жалобы
- Жалобщик и обвиняемый
- Тип, описание, доказательства
- Статус, приоритет, назначенный модератор

#### `system_settings` - Настройки системы
- Feature flags
- Лимиты
- Регионы
- A/B тестирование

### Row Level Security (RLS)
- Все таблицы защищены RLS политиками
- Пользователи видят только свой контент или публичный
- Администраторы имеют расширенные права через RPC функции

## 📊 API Endpoints

### Публичные API
- `GET /api/stories` - Получить истории
- `POST /api/stories` - Создать историю
- `GET /api/products` - Получить товары
- `GET /api/orders` - Получить заказы
- `GET /api/reviews` - Получить отзывы

### Защищённые API
- `POST /api/orders/[id]/respond` - Отклик на заказ
- `POST /api/reviews` - Создать отзыв
- `POST /api/chats/mark-read` - Отметить прочитанным
- `DELETE /api/account/delete` - Удалить аккаунт

### Админ API
- `POST /api/admin/subscriptions/grant` - Выдать PRO
- `POST /api/admin/subscriptions/revoke` - Отозвать PRO
- `GET /api/admin/messages` - Получить сообщения
- `DELETE /api/admin/delete-user` - Удалить пользователя

### Рекламные API
- `GET /api/ads` - Получить рекламу
- `POST /api/ads/[id]/impression` - Записать просмотр
- `POST /api/ads/[id]/click` - Записать клик
- `GET /api/banners` - Получить баннеры
