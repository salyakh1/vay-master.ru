# Геолокационные уведомления для мастеров

## Описание

Расширение системы уведомлений: теперь мастера получают уведомления о новых заказах не только по специализациям, но и с учетом расстояния от заказа до их местоположения.

## Что было сделано

1. **Поля геолокации в профиле мастера:**
   - `master_lat` - широта местоположения мастера
   - `master_lng` - долгота местоположения мастера
   - `service_radius_km` - радиус обслуживания в километрах (по умолчанию 50 км)

2. **Функция расчета расстояния:**
   - `calculate_distance_km()` - использует формулу гаверсинуса для расчета расстояния между двумя точками на Земле

3. **Обновленная функция уведомлений:**
   - `notify_masters_on_new_order()` - теперь проверяет расстояние между координатами заказа и мастера
   - Если расстояние <= радиуса обслуживания → создается уведомление
   - Если координат нет у мастера или заказа → уведомление создается как раньше (без проверки расстояния)

4. **UI в профиле мастера:**
   - Поле для ввода адреса
   - Кнопка "Найти" для геокодирования адреса
   - Выбор радиуса обслуживания (5, 10, 20, 50, 100, 200 км)
   - Отображение определенных координат

## Как применить

### Шаг 1: Применить SQL миграцию

1. Откройте Supabase Dashboard: https://supabase.com/dashboard
2. Выберите ваш проект
3. Перейдите в раздел **SQL Editor**
4. Откройте файл `supabase/master_location_notifications.sql`
5. Скопируйте весь SQL код из файла
6. Вставьте код в SQL Editor
7. Нажмите **Run** (или F5)

Это создаст:
- Поля `master_lat`, `master_lng`, `service_radius_km` в таблице `profiles`
- Функцию `calculate_distance_km()` для расчета расстояния
- Обновленную функцию `notify_masters_on_new_order()` с проверкой расстояния

### Шаг 2: Проверка

После применения миграции проверьте:

1. **Поля добавлены:**
   ```sql
   SELECT master_lat, master_lng, service_radius_km 
   FROM profiles 
   WHERE role = 'master' 
   LIMIT 1;
   ```

2. **Функция расчета расстояния работает:**
   ```sql
   SELECT calculate_distance_km(55.751244, 37.618423, 55.755826, 37.617299);
   -- Должно вернуть расстояние в км между двумя точками в Москве
   ```

## Как это работает

### Для мастера:

1. **Настройка зоны обслуживания:**
   - Мастер заходит в свой профиль → Настройки
   - В разделе "Зона обслуживания" вводит адрес (например: "Москва, ул. Ленина, 10")
   - Нажимает "Найти" → система определяет координаты адреса
   - Выбирает радиус обслуживания (5, 10, 20, 50, 100, 200 км)
   - Сохраняет настройки

2. **Получение уведомлений:**
   - При создании нового заказа система проверяет:
     * Соответствует ли категория заказа специализациям мастера
     * Есть ли координаты у заказа и мастера
     * Если да → вычисляет расстояние
     * Если расстояние <= радиуса обслуживания → создает уведомление
   - В уведомлении указывается расстояние до заказа (например: "на расстоянии 12.5 км")

### Логика работы:

```
При создании заказа:
├─ Найти мастеров по специализации
├─ Для каждого мастера:
│  ├─ Есть координаты у мастера И заказа?
│  │  ├─ ДА → Вычислить расстояние
│  │  │  ├─ Расстояние <= радиуса обслуживания?
│  │  │  │  ├─ ДА → Создать уведомление (с указанием расстояния)
│  │  │  │  └─ НЕТ → Не создавать уведомление
│  │  │  └─ Ошибка расчета → Создать уведомление (без расстояния)
│  │  └─ НЕТ → Создать уведомление (как раньше, без проверки расстояния)
```

## Преимущества

1. **Релевантные уведомления** - мастера получают только заказы в их зоне обслуживания
2. **Гибкость** - если координат нет, система работает как раньше
3. **Автоматизация** - все работает автоматически через триггер БД
4. **Информативность** - в уведомлении указывается расстояние до заказа

## Важные замечания

1. **Обратная совместимость:**
   - Если у мастера нет координат → уведомления работают как раньше (по специализациям)
   - Если у заказа нет координат → уведомления создаются без проверки расстояния

2. **Геокодирование:**
   - Используется существующий API `/api/geocode`
   - Адрес геокодируется через Nominatim (OpenStreetMap)
   - Результаты кэшируются в таблице `geocoding_cache`

3. **Радиус по умолчанию:**
   - Если мастер не указал радиус → используется 50 км
   - Мастер может изменить радиус в любой момент в настройках профиля

4. **Производительность:**
   - Индексы на `master_lat`, `master_lng` для быстрого поиска
   - Функция расчета расстояния оптимизирована (IMMUTABLE)
