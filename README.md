# VayMaster - Социальная сеть для мастеров и продавцов

Платформа для строителей, автомехаников и продавцов строительных материалов и инструментов.

## Возможности

- 🔐 **Аутентификация с выбором роли**: Мастер, Продавец, Клиент
- 📱 **Лента публикаций**: Создание постов, лайки (стиль VK)
- 👤 **Профили пользователей**: Персональные страницы для каждой роли
- 💬 **Система чатов**: Общение между пользователями в реальном времени
- 🛒 **Каталог товаров**: Интернет-магазин для продавцов (стиль vseinstrumenti.ru)
- 🔍 **Поиск и фильтрация**: Поиск товаров по категориям и названию

## Технологии

- **Frontend**: Next.js 14, React, TypeScript, Tailwind CSS
- **Backend**: Supabase (PostgreSQL, Auth, Realtime)
- **Deployment**: Vercel

## Установка

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd vay-master.ru
```

2. Установите зависимости:
```bash
npm install
```

3. Настройте переменные окружения:
Создайте файл `.env.local` (можно начать с `env.example`):
```
NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
SUPABASE_SERVICE_ROLE_KEY=your_service_role_key
```

4. Настройте базу данных:
- Создайте проект в [Supabase](https://supabase.com)
- Выполните SQL скрипт из `supabase/schema.sql` в SQL Editor вашего проекта Supabase

5. Запустите проект:
```bash
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.

## Структура проекта

```
├── app/                    # Next.js App Router
│   ├── auth/              # Страницы аутентификации
│   ├── feed/              # Лента публикаций
│   ├── profile/           # Профили пользователей
│   ├── chats/             # Система чатов
│   └── products/          # Каталог товаров
├── components/            # React компоненты
├── lib/                   # Утилиты и конфигурация
│   └── supabase.ts       # Supabase клиент
└── supabase/             # SQL схемы
    └── schema.sql        # Схема базы данных
```

## Роли пользователей

### Мастер (Master)
- Создание публикаций о своей работе
- Просмотр заказов и предложений
- Общение с клиентами через чаты

### Продавец (Seller)
- Создание и управление товарами
- Каталог с категориями и фильтрами
- Общение с покупателями

### Клиент (Client)
- Просмотр ленты публикаций
- Поиск мастеров и товаров
- Заказ товаров и услуг через чаты

## Развертывание на Vercel

1. Подключите репозиторий к Vercel
2. Добавьте переменные окружения:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
3. Деплой автоматически запустится
