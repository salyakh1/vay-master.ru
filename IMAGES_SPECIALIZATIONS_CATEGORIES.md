# Как добавить картинки для скролла «Готовы помочь» и фильтра категорий товаров

**Важно:** сначала выполни оба SQL-скрипта в Supabase (шаг 1). Без них колонки `image_url` нет в таблицах, и API специализаций может вернуть ошибку (блок «Готовы помочь» не загрузится).

---

## 1. Выполнить миграции в Supabase

В **Supabase Dashboard** → **SQL Editor** выполни по очереди:

**Специализации (скролл на главной):**
```sql
-- Файл: supabase/add_specialization_image_url.sql
ALTER TABLE public.specializations
  ADD COLUMN IF NOT EXISTS image_url TEXT;
```

**Категории товаров (фильтр на странице «Товары»):**
```sql
-- Файл: supabase/add_product_category_image_url.sql
ALTER TABLE public.product_categories
  ADD COLUMN IF NOT EXISTS image_url TEXT;
```

После этого в таблицах появятся колонки `image_url`.

---

## 2. Загрузить картинки и получить ссылки

### Вариант A: Supabase Storage

1. В Supabase: **Storage** → создай bucket (например `specialization-images` и `category-images`), сделай его **Public**.
2. Загрузи файлы (рекомендуемый размер для карточек: **140×140** для специализаций, **96×96** для категорий).
3. Для каждого файла открой его → **Copy public URL** — это и будет `image_url`.

### Вариант B: Внешние ссылки

Можно использовать любые публичные URL картинок (твой CDN, облако и т.д.). Главное — ссылка должна открываться в браузере и отдавать изображение.

---

## 3. Прописать картинки (через админ-панель или Supabase)

### Вариант A: Админ-панель (рекомендуется)

1. Войди в **админ-панель** под учёткой с ролью супер-админ или модератор.
2. В меню выбери **«Картинки»** (`/admin/images`).
3. В блоке **«Специализации»** для каждой строки укажи URL картинки в поле и нажми **«Сохранить»**.
4. В блоке **«Категории товаров»** сделай то же самое для нужных категорий.

Если миграции ещё не выполнены, на странице появится предупреждение с текстом миграции — выполни его в Supabase SQL Editor и обнови страницу.

### Вариант B: Вручную в Supabase

**Специализации:** Supabase → Table Editor → таблица **`specializations`** → в колонке **`image_url`** вставь ссылку на картинку и сохрани строку.

**Категории:** Table Editor → **`product_categories`** → колонка **`image_url`** — вставь ссылку и сохрани.

Если `image_url` пустой — на сайте подставится картинка-заглушка (Picsum по slug).

---

## 4. Как это подхватывается в коде

- **Специализации:** API ` /api/specializations/with-counts` уже запрашивает `image_url`. Если в строке он задан — в скролле «Готовы помочь» покажется твоя картинка; если пусто — заглушка по slug.
- **Категории:** на странице товаров категории загружаются через `select('*')`, поэтому после добавления колонки `image_url` он подхватится сам. В фильтре будет твоя картинка при заполненном `image_url`, иначе — заглушка.

---

## Рекомендации по картинкам

| Место              | Рекомендуемый размер | Формат   |
|--------------------|----------------------|----------|
| Скролл «Готовы помочь» | 140×140 px           | JPG/PNG/WebP |
| Фильтр категорий   | 96×96 px (или 48×48) | JPG/PNG/WebP |

Один размер для каждой группы — карточки будут ровными, без растягивания (используется `object-cover`).
