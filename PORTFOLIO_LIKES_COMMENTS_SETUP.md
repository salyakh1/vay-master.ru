# Настройка лайков и комментариев для портфолио

## Что нужно сделать:

1. **Применить SQL схему:**
   - Откройте Supabase Dashboard → SQL Editor
   - Скопируйте содержимое `supabase/portfolio_likes_comments_schema.sql`
   - Выполните SQL скрипт

2. **Проверка:**
   - Убедитесь, что таблицы `portfolio_likes` и `portfolio_comments` созданы
   - Проверьте, что в таблице `portfolio_items` добавлена колонка `likes_count`

## Что добавлено:

- **Таблица `portfolio_likes`** - для хранения лайков работ портфолио
- **Таблица `portfolio_comments`** - для хранения комментариев к работам
- **Колонка `likes_count`** в `portfolio_items` - счетчик лайков
- **RLS политики** - для безопасного доступа к данным
- **Триггеры** - для автоматического обновления счетчика лайков

## Функциональность:

- ✅ Лайки работ портфолио
- ✅ Комментарии к работам
- ✅ Счетчик лайков
- ✅ Отображение автора работы
- ✅ Время публикации
- ✅ Форма для добавления комментариев
